# Estructura del proyecto Mi Tienda Web

Proyecto web integrador del curso Fundamentos de Desarrollo Web.

## Carpetas

- paginas/: contiene las páginas secundarias, como el catálogo y contacto.
- css/: almacena los estilos visuales de la página web.
- js/: contiene los códigos JavaScript para agregar interactividad.
- componentes/: guarda el encabezado y el pie de página reutilizables.
- backend/: contiene los archivos relacionados con el servidor.
- docs/: almacena la documentación del proyecto.

## Convenciones

- Nombres en minúscula, sin espacios ni tildes.
- Una responsabilidad por archivo.
